## 🛠️ Customization Guide

### Change Primary Color
Edit `style.css` line 6-7:
```css
--primary: #3B82F6;        /* Your color here */
--accent: #8B5CF6;         /* Complementary color */
```

### Adjust Animation Speed
Edit `style.css` line 18-20:
```css
--transition-fast: 150ms;   /* Make faster/slower */
--transition-base: 250ms;
--transition-slow: 350ms;
```

### Modify Typing Roles
Edit `script.js` line 36-41:
```javascript
const roles = [
    'Your Role 1',
    'Your Role 2',
    'Your Role 3'
];
```

### Update Statistics
Edit `index.html` hero stats section:
```html
<span class="stat-number" data-target="10">0</span>
<!-- Change data-target to your number -->
```
